Production-Grade Compiler Capabilities (v0.2.0)

        
Everything compiled ahead-of-time into readable TypeScript with strict build-time validation.

      

      

        

          ROUTING & BATCHES
          
Per-Item IF/Switch & Positional Merge

          
Deterministic per-item branching across rules and expressions, reconverging batch isolation, and positional Merge across up to 10 destination ports.

        

        

          MESSAGING
          
RabbitMQ Publishers & Ack Triggers

          
Exchange-mode confirm publishers plus queue consumers that acknowledge only after workflow success, requeue on failure, and drain gracefully on SIGINT/SIGTERM.

        

        

          BINARY & STORAGE
          
S3 v1, Multipart & Anti-Zip-Bomb

          
S3 file downloads, HTTP multipart binary uploads, Convert to JSON File, Edit Fields binary preservation, and ZIP/GZIP decompression with strict Zip-Bomb & Zip-Slip guards.

        

        

          CONTROL FLOW
          
Bounded Polling, Wait & Stop/Error

          
Single-entry polling loops capped by N8N_TO_FASTIFY_POLL_MAX_ATTEMPTS, dynamic runtime Wait intervals, disabled-node passthrough, and terminal Stop and Error nodes.

        

        

          CODE & EDIT FIELDS
          
$env, --dependencies & JSON Output

          
Runtime $env access, declared npm --dependencies, legacy $node Proxy bindings, continueRegularOutput, and Edit Fields v3.4 raw JSON Output.

        

        

          SECURITY & OPS
          
--strict Checks, Traces & Error Redaction

          
Fail-fast --strict diagnostics, opt-in metadata-only JSON traces (N8N_TO_FASTIFY_TRACE=1), and correlation-ID webhook 500 error redaction.
